メンタルヘルス指針（労働者の心の健康の保持増進のための指針）

ざっくり： 事業場でメンタルヘルスケアをどう進めるかの基本設計。第1章の一次・二次・三次予防、管理監督者の役割、職場環境改善などを理解する中心資料。

一次予防不調を未然に防ぐ。ストレスチェックの活用や職場環境改善など。
二次予防不調を早期に発見し、適切な対応につなぐ。
三次予防職場復帰支援・再発防止。

長時間労働者等への医師による面接指導

ざっくり： 医師が長時間労働者の健康状態を確認し、必要な就業上の措置について事業者へ意見する仕組み。面接そのものが休職を自動決定するわけではない。

  • 一般の労働者：月80時間超の時間外・休日労働＋疲労蓄積＋本人の申出 → 面接指導義務
  • 研究開発業務従事者：月100時間超 → 本人の申出なしでも面接指導義務

職場復帰支援の手引き

ざっくり： 心の健康問題で休業した労働者について、休業開始から復職、復職後のフォローまでを組織的に進めるための手引き。三次予防の中心資料。

パワーハラスメント防止指針

ざっくり： パワハラは「優越的な関係」「業務上必要かつ相当な範囲を超える」「就業環境が害される」の要素で整理する。代表的6類型は、身体的攻撃、精神的攻撃、人間関係からの切り離し、過大な要求、過小な要求、個の侵害。

重大な問題行動をした労働者へ、業務上必要かつ相当な範囲で一定程度強く注意することが、直ちにパワハラになるとは限らない。

健康情報・個人情報の取扱い

ざっくり： 健診、ストレスチェック、面接指導などで扱う心身の情報は機微性が高い。誰が、何の目的で、どの範囲の情報を扱うかを規程化して適正に管理する。

第三者提供は原則として本人同意。医師・保健師だけでなく、制度の実施事務を扱う者の守秘義務にも注意。

安全配慮義務：ここだけは一本につなげる

1. 会社と従業員は労働契約関係にある。

2. 使用者は労働者が生命・身体等の安全を確保しながら働けるよう配慮する義務を負う（労働契約法5条）。

3. 安衛法には健診・面接指導・ストレスチェック等の具体的ルールがある。

4. しかし、安衛法を守ったことが安全配慮義務の全部を自動的に満たすとは限らない。個別事情によって民事上の責任が問題になり得る。

5. 法的な義務主体は企業。現場での履行には管理監督者・人事・産業保健スタッフ等が関与する。
