MO-211 Practice Study Method

HOW TO LEARN FOR A PERFORMANCE-BASED EXAM

「知っている」から
「手が動く」へ。

MO-211は、用語を見て答えるだけではなく、Excel上で目的の状態を作れることが重要です。そこで、このサイトでは「思い出す → 操作する → 結果を確認する」を学習の中心にします。

練習問題へ戻る Certiport公式 試験チュートリアル ↗

本番では、まず「動詞」を読む

CertiportのMOS Microsoft 365 Apps試験チュートリアルでは、1回の試験で5～8個のプロジェクトに取り組み、各プロジェクトでは1～7個のタスクを処理すると説明されています。プロジェクトファイルを実際に編集し、タスクを移動すると変更内容は保存されます。完了前であればタスクへ戻って修正もできます。

1動詞作成する／変更する／保護する／集計する
2対象セル／範囲／シート／ブック／グラフ
3場所どのリボンタブ・ダイアログか
4操作必要な設定だけを行う
5確認指示どおりの状態になったかを見る

本番用の合言葉：「動詞 → 対象 → 場所 → 操作 → 確認」。分からないときほど、いきなりリボンを探し回らず、この順番で指示を分解します。

定着させるときは「読む」より「思い出す」

学習研究では、答えや手順をもう一度読むだけより、いったん情報を閉じて自分の記憶から取り出す練習（retrieval practice）を行う方が、後で思い出せる可能性を高めることが繰り返し示されています。また、一度に詰め込むより学習を時間的に分散する方法も、長期保持に有利です。

① まず見ないでやる

問題を見たら、ヘルプを開く前にExcelを操作。場所が思い出せなくても30～60秒は自力で探す。

② 答えを見たら閉じる

操作場所・図・公式ヘルプを確認したら、そのまま写さず一度閉じ、もう一度ゼロから再現する。

③ 日を空けて再現する

同じ操作を翌日、数日後、1週間後にも再挑戦。サイトの復習キューはこの考え方を使う。

④ 似た機能を混ぜる

Flash FillとFill Series、Goal SeekとScenario Managerなど、似たものを交互に解いて「使い分け」を練習する。

このサイトの「1日 → 3日 → 7日 → 14日 → 30日」という復習間隔は、spacingの研究を実用的に取り入れるためのサイト上の目安です。研究がこの日程そのものを唯一の正解として示しているわけではありません。

実技問題は4段階で判定する

Level 3問題文だけで場所を思い出し、最後まで自力で操作できる
Level 2リボンタブ程度のヒントで操作できる
Level 1解答を見れば再現できるが、最初は手が止まる
Level 0解答を見ても意味や操作の流れがまだ曖昧

目標は「読めば分かる」ではなく、問題文を見た瞬間に最初のクリック先が浮かぶ状態です。関数なら「何を返す関数か」と「引数の並び」、リボン操作なら「どのタブのどのグループか」を声に出してから操作すると、操作とことばを結び付けやすくなります。

本番で頭が真っ白になったら

  1. 対象セルやオブジェクトを先に選ぶ。 選択するとコンテキストタブが出る操作が多い。
  2. 指示の名詞ではなく動詞を見る。 「スライサー」より「挿入する」、「値フィールド」より「表示方法を変更する」に注目。
  3. 似た機能を2択まで絞る。 例：値を制限するなら入力規則、見た目を変えるなら条件付き書式。
  4. 結果を見て検算する。 数式なら値、ピボットなら集計、保護なら実際に編集できるか、という形で確認する。
  5. 詰まり続けない。 Certiportの試験UIではタスクを見直せるため、いったん先へ進み後で戻る戦略も取れる。

試験当日に「脳を働かせる」ための現実的な準備

睡眠を削って詰め込まない

2024年のメタ分析では、1晩だけ睡眠を2～6時間に制限しても眠気が増え、持続的注意の反応時間と注意抜けが悪化しました。別の2024年メタ分析では、3～6.5時間の睡眠制限は記憶形成にも小さいながら有意な悪影響を示しています。

直前は新規学習より再生確認

試験直前に新しい機能を大量に増やすより、「この指示なら最初にどこをクリックするか」を短い検索練習で確認します。最後の1～2日は復習キューとプロジェクト模擬を中心にします。

短い運動は選択肢になる

2025年の30件のメタ分析を統合したmeta-reviewでは、単回の運動後に認知機能が小～中程度改善しました。試験前に激しい運動をする必要はなく、普段問題なく行える短い歩行などを選択肢として考える程度で十分です。

最初の1分でリズムを作る

開始直後は「動詞→対象→場所→操作→確認」の順を守り、難問に飛びつかない。作業手順そのものをルーチン化しておくと、焦ったときにも戻る場所ができます。

運動・睡眠に関する記載は一般的な研究結果の紹介です。体調や服薬等がある場合に個別の行動を推奨するものではありません。

このサイトで実装している学習設計

実技問題では、いきなり手順を見せず、まず「動詞・対象・場所」を思い出すための段階ヒントを表示します。解答後は、操作場所、数式例、Excel風の模式図、似た機能との違い、実際にやり直す手順、Microsoft公式リンクをまとめて表示します。

さらに「自力でできた」「ヒントあり」「要復習」で自己判定し、苦手スキルをブラウザ内の復習キューへ保存します。正解だけを増やすのではなく、自力再現できる回数を増やすことを目的にしています。

知識問題は選択肢の順番を毎回シャッフルし、答える前に任意で自信度を記録できます。高い自信で間違えた項目は「思い違い」の可能性があるため優先復習。実技問題は各スキル2パターン以上とプロジェクト模擬を用意し、同じ機能を異なる文脈で再現する練習にしています。
