# MO-211 Excel Expert Practice

papanda925向けの **Microsoft Excel Expert (Microsoft 365 Apps) / MO-211** 非公式練習サイトです。

公開URL（GitHub Pages）:

- https://papanda925.github.io/mo211/

## 方針

- Microsoft Learnで公開されているMO-211の試験範囲を学習マップとして使用します。
- 問題文、実技課題、解説はこのサイト用に独自作成します。
- 実際の試験問題、試験ダンプ、Microsoftの講師用Courseware・Study Guideの問題文や配布ファイルは掲載しません。
- Excelを実際に操作して確認する「実技課題」と、機能の使い分けを確認する「知識チェック」を併用します。

## 公開されている主な試験分野

1. ブックのオプションと設定の管理
2. データの管理および書式設定
3. 高度な数式およびマクロの作成
4. 高度なグラフおよびテーブルの管理
