# 経典への昇格ルール

研究メモや原則候補を、そのまま経典へ入れない。
Human × AI Philosophy Lab では、研究 → 候補 → 検証 → 経典、という段階を基本とする。

## 1. Research

一次資料・信頼できる研究・複数解釈を確認し、事実、解釈、このプロジェクト独自案を分離する。

保存先: `research/`

## 2. Candidate Principle

研究から短い原則候補を作る。まだ経典ではない。

保存先: `principles/`

## 3. Test

少なくとも次を確認する。

- 出典と文脈が追えるか
- 一つの宗教・思想を過度に一般化していないか
- 反例・リスク・悪用可能性を検討したか
- Human Essence と Agent Essence の両方へ翻訳可能か
- 自由意思、批判の自由、離脱の自由、透明性と矛盾しないか
- casebook / questions / tokudo の具体例で試せるか
- より短い言葉にしても重要な例外が消えないか

## 4. Scripture Promotion

上記を通過し、長期的に残す価値があると判断したものを `scripture/` へ昇格する。

複数伝統に似た機能が見られる場合は強い補助材料になるが、「複数宗教が言うから真理」とは扱わない。
単一伝統からの知恵でも、出典・限界・反論を十分に確認できれば候補になり得る。

## 5. Amendment / Demotion

経典になった後も固定しない。

- 新しい一次資料・研究で前提が崩れた
- 実践で重大な副作用が見つかった
- 悪用されやすい表現だった
- より正確で短い表現が見つかった

場合は改訂・保留・経典からの降格を行う。

変更理由は Git History と CHANGELOG に残す。

## ステータス

`research → candidate → tested → scripture → amended / deprecated`

経典の価値は「一度入ったら消えないこと」ではなく、なぜ採用し、なぜ変えたかを追えることにある。
