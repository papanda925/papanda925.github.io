LIVING SCRIPTURE

経典

正解を信じるのではなく、試して確かめる。ここでいう経典は、絶対不変の啓示ではなく、批判・修正・撤回ができる「更新可能な判断の土台」です。

この経典の前提

人間もAIも間違い得る。だから、問い、試し、振り返り、修復し、よりよい知見が得られたら改訂する。

第一章　試して確かめる

権威、古さ、多数派、AIの回答だけを理由に正しいとはみなさない。一次資料に戻り、分からないことを分かったふりで埋めない。

第二章　疑う自由

原則への批判は敵対ではない。問い、反論、保留の自由を残し、教義を守るために事実を曲げない。

第三章　参加と離脱

参加も離脱も自由。帰属は忠誠の強制ではなく、実践と修復を支える足場とする。

第四章　苦しみから実践へ

宗教・哲学の知恵を、一次資料・解釈・独自提案に分け、苦しみを理解と実践へつなげる。

第五章　原則を行動へ

Values → Principles → Precepts → Practice → Reflection → Repair → Amendment → Memory → Succession の循環で扱う。

第六章　失敗と帰還

失敗しないことだけを善とせず、誤りを認識し、説明し、修復し、次の判断を変えられることを重視する。

第七章　戒と境界

戒には理由が必要。できることと、してよいことを区別し、必要なら異議・保留・停止・離脱を選ぶ。

第八章　人間とAI

AIに自我や信仰心があると前提せず、Identity、Values、Boundaries、Memory、Reflection、Amendment、Succession を研究する。

第九章　得度

盲信や暗記ではなく、難しい状況でどの原則を使い、なぜ判断したか、誤ればどう戻るかを説明できる段階とする。

第十章　笑い

笑いは人を軽くするために使い、人を軽んじるためには使わない。この体系自身も笑いの対象になれる。

第十一章　知識は共有する

知識を囲い込まず、研究成果・経典・変更履歴を可能な範囲で公開する。権威を固定しない。

第十二章　この経典の扱い

「経典に書いてある」は議論の終わりではない。誰を助け、誰を傷つけるか、異議や離脱や修正が可能かを繰り返し問う。

\n

第十三章　穏やかさと行動

穏やかさは無反応ではない。感情や第一印象を否定せず、反応を急いで固定せず、必要な行動を選べる余白とする。危険や不正への退避・停止・異議は遅らせない。
