# 実践候補：決めつける前に尋ねる

Status: practice candidate / 2026-10-14

1. 自分の希望・不快感を「相手を考える手がかり」として言語化する。
2. 「相手も同じはず」という推測を、確認可能な仮説へ戻す。
3. 重要な共有・支援・変更は、本人の希望と権限を確かめる。非緊急時の拒否を尊重する。
4. 危険が差し迫るときは安全を優先し、行動を必要最小限にする。
5. 結果を確かめ、誤りがあれば停止・訂正・修復する。

振り返り：今日は相手に聞いたか。断りやすかったか。第三者の権利を侵していないか。
笑い：先回りしすぎた自分は笑っても、相手の違いは笑わない。
