# 実践候補｜予定と結果を区別する3分チェック

状態：practice candidate（2026-10-29）。宗教儀礼ではなく研究所独自の実務応用。

1. **意図**：「何をしたい／するつもりか」を短く言う。
2. **条件**：「何がそろえばできるか」「何が変われば難しいか」を確認する。
3. **相手への影響**：相手がその予定を前提に動くなら、確認時刻・変更連絡の方法を決める。
4. **実行前**：権限と期限、撤回の有無を再確認する。緊急時は安全上の別根拠を人間が判断する。
5. **結果**：実行・到達・未完了を分けて報告し、失敗時は必要な修復をする。

**問い**：不確かなことを断言していないか。自分の希望を、他者の同意や実行結果と混同していないか。

**注意**：「インシャーアッラー」を単なる曖昧な返事や責任回避の言葉と決めつけない。宗教的表現を契約のルールに置き換えない。

## 2026-10-29 夜：相手がすでに準備した場合

1. 相手の**依拠**を尋ねる（時間・予約・費用・人員。不要な個人情報は収集しない）。
2. 不確実性を伝えたかだけでなく、**確認期限と変更連絡**が共有されたか確かめる。
3. 予定が変われば、可能な代替策を提示する。ただし謝罪・接触を拒む相手に再送を強要しない。
4. AIでは予定、権限、API受理、送信、到達、確認を区別。権限失効後の実行は禁止。
5. 連絡できない場合は「通知済み」と偽らず未達を記録。法的・安全上の義務は適切な人間の判断へ。

これは宗教上の義務の要約ではなく研究所独自の実務案。出典比較と反例：[夜の研究](../research/2026-10-29-evening-inshallah-conditional-promises-reliance.md)。
