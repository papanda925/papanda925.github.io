# 実践候補：短い返事の意味を確かめる

状態：practice candidate（2026-10-28 夜）。

## 人間のための30秒確認
1. 私はいま何に「はい」と答えようとしているか。
2. 相手と私の理解は一致しているか。
3. これは挨拶・祈り・意見・約束・実行許可のどれか。
4. 分からなければ「確認させてください」と言えるか。

## AIエージェントのための境界確認（設計案）
1. Acknowledged：受信した事実を記録する。
2. Meaning：依頼の対象と範囲を特定し、不明なら保留する。
3. Authorized：許可の主体・目的・期限・撤回状態を別に確認する。
4. Pre-action check：外部操作の直前に権限失効を再確認する。
5. Executed / Delivered：実行と到達を分けて監査する。

これは研究上の設計候補であり、実装済みの停止保証ではない。法的な契約同意や宗教儀礼を一つのアルゴリズムで裁定しない。
