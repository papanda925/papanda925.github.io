# 実践候補｜意図・行為・影響の3分チェック

状態：practice candidate（2026-10-30）。宗教儀礼ではなく研究所独自の応用。

1. **意図**：何を助けようとしたか。思い込みや期待は何か。
2. **行為**：実際に何をしたか。予定と実行を混同していないか。
3. **影響**：相手や周囲に何が起きたか。未確認の部分は何か。
4. **修復**：誤りや害があれば、訂正・相談・必要な支援を選ぶ。相手の同意・安全・拒否を尊重する。
5. **自制**：他者の病気・被害・貧困を、本人の「業」のせいと決めつけない。

AIへの翻訳：Intent / Action / ObservedImpact / Unknowns / Repair を区別する。宗教的な因果を実証済みデータとして扱わず、道徳スコアを付けない。
