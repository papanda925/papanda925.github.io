# 実践候補｜「はい」の前に、意味を一つ確かめる

状態: practice / 2026-10-28。信仰の作法を変更する提案ではなく、日常の対話の練習。

## 3分の実践
1. 相手の話の要点を一文で言い直す。
2. 分からない範囲・実行できない範囲を明示する。
3. 同意・実行が必要なら、目的・期限・撤回できるかを確認する。
4. すぐ決められない場合は「確認してから答える」と伝える。
5. 後で約束したことと実際にできたことを区別して振り返る。

**注意**：祈りで唱える「アーメン」は各宗教の実践に属する。ここでの「はい」の点検は本研究独自の日常応用であり、礼拝の適否を裁定するものではない。

## AIに置き換えたとき
`received`、`understood`、`authorized`、`executed`、`delivered`を分ける。重要操作では権限の期限・撤回・目的を確認し、不明なら停止する。緊急・法令上の例外は人間の責任者へ渡す。
