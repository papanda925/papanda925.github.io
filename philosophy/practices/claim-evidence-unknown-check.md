# 実践：Fact / Hypothesis / Unknown の三欄点検

Status: practice candidate / 2026-10-20

判断前に30秒だけ次を記す。
- Fact: 直接確認できた事実と出典
- Hypothesis: まだ検証していない説明と確信の程度
- Unknown: 判断に影響する未確認事項
- Next check: 誰が、いつ、何を確認するか
- Urgency / Authority: 今すぐ必要な保護行動と、その権限
- Repair: 間違いが判明したとき、誰に訂正を届けるか

「不明」は停止の理由にも、断定の免罪符にも使わない。重大な危害が切迫する場合は必要最小限の安全行動を優先する。相手を追い詰める問答に使わない。
