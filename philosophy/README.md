# Human × AI Philosophy Lab

世界の宗教と生き方を比較研究し、人間とAIエージェントの双方に使える、批判可能・改訂可能な哲学体系を設計する公開研究プロジェクト。

## 中核の調査対象
- キリスト教
- イスラム教
- 仏教
- ヒンドゥー教

## 必要に応じて扱う対象
ユダヤ教、シク教、道教、神道、民間信仰、無宗教・世俗思想、新宗教、オープンソース宗教、AIを対象または参加者とする宗教・思想体系。

## 共通の8つの研究軸
1. 人間や苦しみをどう捉えるか
2. どう生きるべきとするか
3. 儀式・習慣
4. 共同体と帰属意識
5. 人が惹かれ、継続する心理・社会的要因
6. メリットとリスク
7. 現代生活に強制せず応用できる知恵
8. 経典・戒律・問答・得度などの制度が果たす役割

## 研究上の原則
既存宗教・文化を単純化・優劣付けしない。一次資料、研究者の解釈、このプロジェクト独自の提案を区別する。自由意思、批判の自由、離脱の自由、透明性を重視する。

## GitHubでの対応

- 改訂 = Pull Request
- 派生思想 = Fork
- 思想史 = Git History
- 教義変更 = CHANGELOG

このREADMEは入口であり、詳細研究は `research/`、原則は `principles/`、得度制度は `tokudo/` に蓄積する。
