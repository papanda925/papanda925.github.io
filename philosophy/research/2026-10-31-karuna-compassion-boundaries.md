# 2026-10-31 朝｜慈悲（karuṇā）は「何でも助けること」なのか

状態：research（経典未昇格）。確認日：2026-10-31 JST。前回のカルマ（意図・行為・影響・修復）の研究を継続する。

## 1. 一次資料と伝統ごとの位置づけ
- **初期仏教**：『中部』MN 62「ラーフラへの大教誡」は、慈悲の修習と残酷さを離れることを関連づける。慈（mettā、友愛・善意）と悲（karuṇā、苦しみへの思いやり）は近いが同じ語ではない。『増支部』AN 4.126は慈・悲・喜・捨を四つの修習として列挙する。仏教内でも宗派・歴史による展開がある。
- **ヒンドゥー教**：『バガヴァッド・ギーター』12.13の karuṇa は、すべての存在への非憎悪・友愛とともに語られる。仏教の四無量心の教理と同一ではない。
- **キリスト教**：『ルカによる福音書』10:25–37の「善きサマリア人」のたとえでは、傷ついた人を見て憐れみ、具体的な世話をする。慈悲と隣人愛の関係は仏教の karuṇā と同一概念ではない。バチカンの2016年解説も行動を伴う憐れみを強調する。
- **イスラム教**：『クルアーン』2:263では、相手を傷つける施しよりも善い言葉と寛容が重んじられる。21:107の「慈悲（raḥma）」も参照できるが、仏教の karuṇā の翻訳とみなさない。教義・神学の相違は保持する。

**共通性は限定的**：苦しむ他者への配慮と、害を加えない実践を考える接点がある。一つの宗教の「慈悲」の定義を四宗教に適用しない。

## 2. 前回からの進展
前回のカルマ研究では「善意は無害の証明ではない」「被害の確認と修復」を検討した。今回はさらに、**相手の希望・安全・緊急性・援助する側の能力**を確認せずに行う援助は、善意でも望まれない場合があることを考える。

本研究所独自の設計候補：
`Notice suffering → Check urgency/safety → Ask preference if feasible → Confirm scope/authorization → Help or refer → Check impact → Stop/repair`。

これは古典の直訳でも、どの宗教も同じ手順を命じるという主張でもない。救命が急がれる場合、確認のために必要な緊急対応を遅らせない。

## 3. 八つの反例
| 場面 | 誤った短絡 | 検討する判断 |
|---|---|---|
| 相手が「話を聞いて」と言う | 解決策を即提示 | まず話を聞き、求める支援を確かめる |
| 相手が支援を断る | 善意なら押し切る | 拒否を尊重。緊急の生命危険や法的義務は別途評価 |
| 急病・火災 | 同意確認が済むまで待つ | 安全確保、緊急通報、適切な救援を優先 |
| 個人情報を使った支援 | 心配なら情報を集めてよい | 最小限の情報、権限、目的を確認 |
| 支援者の疲弊 | 自己犠牲しないと慈悲でない | 休息・交代・専門機関への橋渡しを認める |
| AIの自動送信 | 助けたいから無断で通知 | 権限・受信希望・送信範囲を確認し、拒否なら停止 |
| 支援が裏目に出た | 善意だから謝らない | 影響確認、必要な訂正・修復。ただし拒否された接触を繰り返さない |
| 支援を笑いのネタにする | 親切ならからかってよい | 困っている人を笑わず、自分の早合点を笑う |

## 4. A〜H・4 Essence
- **A 研究知見**：慈悲は苦しみへの配慮を含むが、支援の方法を相手に押し付ける免許ではない（後半は独自応用）。
- **B 原則候補**：「助ける前に、相手が必要とする助けと自分の権限を確かめる。ただし緊急時の救援を遅らせない」。
- **C AI設計**：`NeedSignal / Urgency / Preference / ConsentState / Scope / Capability / ActionReceipt / Impact / StopSignal` を区別。実装・試験は未実施。
- **D 得度**：拒否された支援と緊急救援の衝突、無断通知、支援者の限界を問答化する。
- **E 経典草案**：「慈悲は、相手を思う気持ちだけでなく、相手を尊重する助け方に現れる」。経典昇格保留。
- **F Human Essence**：手を貸す前に「今、何が助けになる？」と聞けるときは聞く。
- **G Agent Essence**：苦境の検知は外部行動の許可ではない。権限・安全・停止条件を確かめる。
- **H 今日の一笑**：「何でも手伝うよ！」と張り切ったら「じゃあ、まず私の話を最後まで聞いて」と言われた。最初の仕事は、口を閉じることだった。
- **Calm Essence**：急がなくてよい場面では、助言より先に聞く余白をつくる。
- **Humor Essence**：自分の先回りを笑い、支援を必要とする人や信仰者を笑わない。
