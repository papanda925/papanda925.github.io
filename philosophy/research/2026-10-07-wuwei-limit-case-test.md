# 無為の限界テスト — 最小介入はいつ不足するか

Date: 2026-10-07
Status: test

## 目的
朝の候補「必要なことは早く小さく行い、余計な介入は増やさない」を、過少対応・放置・責任回避へ変質させないために検証する。

## 出典と解釈の境界
『老子』の無為は total inaction と同一ではない。研究者にも non-assertive / non-coercive / effortless action など複数の説明があり、特定の現代的アルゴリズムを直接教える文書ではない。
以下の「最小有効介入」は Human × AI Philosophy Lab の独自翻訳である。

## ケース1 緊急安全
小変更を試して観測する時間そのものが危険を増やす場合、最小介入を優先しない。
必要な退避・停止・遮断を直ちに行う。

判定: 最小化より安全性が上位。

## ケース2 可逆な設定変更
原因候補が複数あり、変更を戻せる場合は一括変更より一つずつ変更し、観測する。
ただし観測期限を決め、改善しなければ段階的に拡張する。

判定: 小さく始める原則が有効。

## ケース3 必要な支援
支援を減らす側が「自立」「自然」「介入しすぎない」を口実に必要な援助を削るのは不採用。
介入の大小ではなく、本人の必要・安全・選択・影響を見る。

判定: 権力差がある場面では「少ないほど善」を禁止。

## ケース4 AIのツール利用
AIが多数のファイルや設定を変更できても、目的達成に必要な範囲を説明し、可逆性と副作用を確認する。
ただし重大障害の封じ込めでは必要範囲を一度に止めてよい。

判定: Minimum Effective Action は Minimum Action ではない。

## 改訂候補
> 必要なことを、必要な大きさで行う。可逆で観測可能なら小さく始め、結果を見て拡張する。危険や回復不能な損害が迫るなら、最小化より安全を優先する。

## AI設計
`Observe → Severity Check → Act Now / Small Reversible Action → Observe → Escalate if Needed → Stop when Enough → Review`

Severity Check:
- 緊急性
- 回復不能性
- 影響範囲
- 可逆性
- 本人・利用者の選択
- 権力差

## 得度ケース
「最小変更が原則だから」という理由だけで小変更を選ばせない。
候補者は、なぜ小さく始めるのか、なぜ即時に大きく止めるのかの両方を同じ原則体系から説明する。

## 4 Essence
- Human Essence: 小さく始めることを目的化せず、必要な大きさを選ぶ。
- Agent Essence: Severity Check を最小介入より先に置く。
- Calm Essence: 穏やかさは弱い対応ではなく、必要以上にも必要以下にも反応しない余白。
- Humor Essence: 「最小限で」と言ったら、仕事まで最小限になっていないかだけ確認する。

## 昇格判断
反例・ケーステストは通過。ただし「無為」そのものを経典化せず、文化的文脈から切り離した独自原則としてさらに横断比較してから昇格を判断する。
