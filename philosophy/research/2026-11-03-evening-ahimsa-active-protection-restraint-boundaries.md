# 2026-11-03 夜｜アヒンサー：不害は「不作為」か、慎重な保護行動か
状態：research（経典未昇格）｜出典再確認：2026-11-03 JST｜朝の研究と宗教用語第8回の継続。朝の今日の言葉は維持。

## 1. 夜の発見：ジャイナ教の不害には「積極的な配慮」の面もある
- **一次資料**：『ヨーガ・スートラ』2.30は不害を五つのyamaの一つに挙げる。これだけで「危険を見ても黙るべき」とは読めない。
- **一次資料と注釈を分ける**：『バガヴァッド・ギーター』16.2はahiṃsā、satya、dayā等を並べる。ラーマーヌジャやシャンカラ等の解釈は本文そのものではない。戦場を背景とする全編の緊張を残す。
- **研究者の解説**：Jainpedia「Non-violence」はジャイナ教の不害に、単なる暴力の不在ではない積極的側面があり、現代の一部信徒が平和・環境・動物福祉・貧困の軽減へ応用していると説明する。これは全宗派・全信徒の統一義務ではない。
- **重要な限定**：Jainpedia「Five ‘fundamental vows’」は出家者の大誓戒（mahā-vrata）と在家者の小誓戒（aṇu-vrata）を区別し、在家者にはより大きな害を避けるための例外的な保護行為も論じる。これは現代の個人・AIへ無制限の介入を認めるものではない。
- **宗教の文脈を守る**：『ダシャヴァイカーリカ・スートラ』の引用はJainpediaに掲載された訳を介して確認したもので、原語の独立した校訂本文照合は未実施。

## 2. 朝の研究への修正・精密化
「不害は何もしないことではない」という一般化では不十分。**宗教的誓戒の水準、具体的な危険、行為者の権限、予見可能な害、本人の意思**を分ける。特にジャイナ教では出家者・在家者の実践差が本質的である。
「積極的な保護」は**行動する理由**になり得ても、AIの個人情報送信・代理行為の**実行許可**にはならない。宗教の解説とAI設計案を混ぜない。

## 3. 八反例：不作為・過剰介入・小さな害
| ケース | 誤りやすい短絡 | より適切な検討 |
|---|---|---|
| 1 出家者の誓戒を在家者に強制 | 不害の義務は全員同一 | 大誓戒・小誓戒と伝統内の差を明示 |
| 2 危険な状況を見て沈黙 | 非暴力＝無関心 | 安全な退避・報告・救援の選択肢を検討 |
| 3 支援を口実に連絡先へ機微情報を送信 | 善意＝許可 | 宛先・最小化・同意・法的根拠・緊急性 |
| 4 人を守るために別の害が発生 | 完全無害でなければ行動不可 | 予見可能性、比例性、代替案、権限 |
| 5 AIが危険を推測しただけで警察に通知 | リスク推定＝外部操作権限 | 確度、切迫性、適法性、人間確認を区別 |
| 6 相手が支援を拒む | 支援＝必ず善 | 意思と境界を尊重、例外は個別根拠 |
| 7 発信した危険情報が誤りだった | 訂正も人を傷つける | 誤りを確認し適切な訂正と影響確認 |
| 8 宗教的非暴力を被害者へ押し付ける | 怒り・異議は非倫理 | 感情・安全・異議・救済の権利を区別 |

## 4. A〜H／4 Essence
- **A 研究知見**：不害には積極的な配慮の側面がある一方、ジャイナ教の出家者と在家者では誓戒の水準が異なる。
- **B 原則候補**：害を減らす判断は、放置と過剰介入の両方を比較し、境界と実行許可を別に確かめる。
- **C AI設計**：ObservedRisk → Confidence/Urgency → Authority/Consent/LegalBasis → MinimalOption → HumanReview or Hold → ActionReceipt → Impact/Repair。**机上案・未実装**。
- **D 得度**：出家者の誓戒を在家者へ強制しないこと、保護のための例外を万能の免罪符にしないことを説明する。
- **E 経典・問答草案**：「不害は、動かないことでも、勝手に動くことでもない。害と権限を見極め、必要な一歩を選び直す」。**candidate、昇格保留**。
- **F Human Essence**：相手の状況を見て、沈黙も介入も自動的な正解にしない。
- **G Agent Essence**：危険の発見と、実行の許可を分離し、最小限の行為と停止条件を記録する。
- **H 今日の一笑**：「先回りして全部やります！」と張り切った。最初に頼まれた仕事は「まず、何を頼まれたか聞いて」だった。
- **Calm Essence**：緊急でないときは一拍置いて影響を見積もる。切迫した危険では安全な退避・救援を遅らせない。
- **Humor Essence**：自分の先回り癖を笑い、信仰者や困窮者を笑わない。
