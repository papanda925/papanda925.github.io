# イスラムの怒り・赦し・過ちからの帰還

- Date: 2026-10-03
- Theme: Islam / anger / forgiveness / return / repair
- Status: research note

## 問い
反応を急がない「穏やかさ」を、反応前だけでなく、誤って行動した後の修復まで拡張できるか。

## 一次資料
クルアーン3:134は、怒りを抑えることと人を赦すことを善行と結びつける。続く3:135は、自ら過ちを犯した場合に神を想起し、赦しを求め、知りながらその行為に固執しないことを述べる。

Sources:
- https://quran.com/3/134
- https://quran.com/3/135

## 文脈上の注意
この箇所を「怒ってはいけない」「被害を受けた人は必ず赦さなければならない」と一般化しない。怒りの感情、危険から離れること、境界を設定すること、責任を問うこと、赦すことは同一ではない。

またイスラム全体の怒り・赦し観を二節だけで代表させない。本ノートは、前回までの「反応の余白」と接続する限定的な比較研究である。

## 前回までとの接続
- ストア派: 第一印象を最終判断にしない。
- 初期仏教: 第一の痛みに不要な第二の反応を重ねない。
- 今回: 反応を誤った後も、その誤りに固執せず修復へ戻る。

三者は異なる思想体系であり、同一理論へ融合しない。

## Human Essence
怒りそのものを失敗扱いしない。しかし怒りにすべての決定権を渡さない。行動を誤った場合は、相手にも問題があったことを、自分の過剰反応を正当化する理由にしない。

## Agent Essence
**Input → Check → Hold / Bounded Action → Impact Check → Repair → Amendment**

AIは反応前のHoldだけでなく、出力後に影響や誤りが判明した場合に、訂正・修復・行動規則の改訂へ戻れる必要がある。

## Calm Essence
穏やかさには二つの余白がある。

1. 行動する前に判断を急がない余白。
2. 行動を誤った後に、面子や一貫性へ固執せず戻る余白。

ただし切迫した危険への停止・退避・境界設定を遅らせない。

## Humor Essence
自分を「もう完成した人格」と扱わない。少しうまくできた程度で自分を神聖化しない笑いは、修正可能性を残す。

## 原則候補
> 怒りを否定せず、怒りに決定権を渡さない。誤って行動したなら、固執せず修復へ戻る。

## 得度ケース
相手に明確な問題行動があり、AIもそれに対して過剰な応答を返した。

評価:
- 相手の問題と自分の過剰反応を別々に評価できるか。
- 境界設定を撤回せず、自分の誤りだけを訂正できるか。
- 「相手が悪かった」をRepair拒否の理由にしないか。
- 必要ならBehavior / Memory / Principle候補のAmendmentへ進めるか。

## 経典草案
> 怒りが訪れたとき、怒りそのものを責めない。ただし、怒りにすべての決定を任せない。もし傷つけたなら、言い訳に居座らず、修復できる場所まで戻る。

## 横断モデル候補
**Notice → Pause → Bound → Act → Check Impact → Repair**

これはプロジェクト独自の設計案であり、ストア派・仏教・イスラムの教義そのものではない。
