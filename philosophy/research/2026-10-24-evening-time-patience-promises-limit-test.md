# 時機を誰が決めるか — 忍耐・真実・将来の約束をめぐる限界テスト

- 日付: 2026-10-24 夜（JST）
- 状態: research / counterexample test。経典未昇格。
- 継続元: [10月24日朝・変化と時機](./2026-10-24-seasons-impermanence-timing.md)
- 問い: 「待つ」「耐える」「未来は不確実」を、責任回避や他者への強制に変えずに使えるか。

## 1. 出典・文脈・相違

### コヘレトの言葉 3:1–11（ユダヤ教・キリスト教の知恵文学）
3:1–8は泣く／笑う、黙る／語る等の対句を並べる。3:11と注解では、人間が神の営みと適切な時を完全に把握できないという限界が重要。「今がその時だ」と他人に命令できる権限を与える文ではない。

一次資料・注解: https://bible.usccb.org/bible/ecclesiastes/3

### 法句経 277（初期仏教）
条件づけられたものの無常を智慧で見るという文脈。認識論的・実践的な洞察であり、イスラム教の神への依拠やコヘレトの神の時機と同一の世界観ではない。

本文: https://www.buddhanet.net/dhammapada/d_path/

### バガヴァッド・ギーター 2.14（ヒンドゥー教）
感覚接触による寒暑・楽苦は生じて去るため、耐えることが説かれる。戦いと義務の対話の一節である。ここから現代の虐待・危険・健康被害に耐える義務を一般化しない。

本文・注解: https://heritage.iitk.ac.in/SBG/2.14

### クルアーン 103:1–3 と 18:23–24（イスラム教）
103章は時間に言及し、信仰・善行・真実と忍耐を相互に勧めることを重視する。18:23–24は「明日必ず行う」という将来への断言を神の意志への言及と結び付ける。いずれも信仰的な文脈を持ち、現代の工程管理や期限免責の技術規格を直接定めるものではない。

本文: https://legacy.quran.com/103 / https://legacy.quran.com/18/23-24

### 本研究の独自仮説
異なる伝統の共通教義を作るのではなく、**時間の不確実性を認めることと、いま負う責任を果たすことは両立できる**、という限定的な設計仮説を試す。宗教的教えの信仰上の真偽は判定しない。

## 2. 六つの反例・悪用可能性

| 事例 | 危険な短絡 | 判断の境界と修復 |
|---|---|---|
| 1. 事故・緊急警告 | 「待つ時だから」対応を遅らせる | 差し迫った危険・被害の拡大を優先判定。権限内で安全確保・通報し、後から記録・検証する。 |
| 2. 悲嘆・療養 | 「変わる時」「耐えるべき」と他人の回復を急がせる | 本人の意思・安全・支援希望を聞く。回復時期を第三者が宣告しない。 |
| 3. 約束と納期 | 「未来は不確実」で約束違反を免責する | 実行可能性を再評価し、変更を早めに通知、代替案・影響・責任を説明する。 |
| 4. AIの古い同意 | 昨日の許可で今日も自動操作する | 実行直前の権限・期限・撤回を確認。不明なら保留し、本人へ確認する。 |
| 5. 忍耐の強制 | ギーターの「耐えよ」やクルアーンの「忍耐」を他人への危険放置命令にする | 宗教文脈を尊重しつつ、本人の安全・離脱・相談・批判の自由を優先する。 |
| 6. 過度な最適化 | 「今やるべき一つ」を常に生産性で選ぶ | 休息、弔い、対話、関係修復も正当な選択。短期効率だけで評価しない。 |

**反例からの修正:** 時機の判断は、時間だけでは足りない。危険度、期限、本人の意思、権限、回復可能性、将来への説明責任を分けて確認する。「待つ」は必ず再確認条件を伴う。

## 3. 実装候補（宗教教義とは別の独自設計）

`Observe → Timestamp → Risk → Deadline → Consent/Authority → Act / Hold / Escalate → Recheck → Record/Repair`

- **Act**: 権限があり、必要性・緊急性・影響を確認できるときに実行。
- **Hold**: 危険が差し迫らず、権限や意思が不明なら保留。再確認の期限と担当を記録。
- **Escalate**: 危険が大きいが本人の意思・権限・対応手段が不明なら、許された連絡先や安全経路に確認・相談。勝手な権限拡大をしない。
- **Record/Repair**: 何を知り、何を知らず、なぜ動き、結果をどう修復したかを残す。記録のための個人情報過剰収集はしない。

この分岐は設計候補であり、医療・法的・緊急対応の具体的な判断基準として検証済みではない。

## 4. A〜H と四つの Essence

**(A) 研究知見**: 時間の限界や変化を知ることは、約束や安全への責任を消さない。忍耐と先送り、受容と放置は別である。

**(B) 原則候補**: 「未来を断言せず、今日の責任を曖昧にしない。待つなら、何を待ち、いつ確かめるかを決める。」

**(C) AI設計**: 時点・危険・期限・同意・権限・再確認・修復を分離し、Act / Hold / Escalate の理由を残す。

**(D) 得度**: 緊急時の待機、将来の約束と不可抗力、同意の撤回、他者への忍耐の強制を問答で検証する。関連: [時機・変化・自律の得度問答](../tokudo/seasons-timing-consent-cases.md)。

**(E) 経典・問答草案**: 「待つことを言い訳にせず、急ぐことを支配にしない。未来を知らぬまま、いまの責任を引き受ける。」反例・文脈・実証不足につき昇格保留。

**(F) Human**: 明日を約束しすぎず、今日必要な連絡・行動・休息を選ぶ。

**(G) AI Agent**: 古い権限や確信で未来を断言せず、保留にも期限と再確認を設ける。

**(H) 今日の一笑（夜の研究用・日次4枠は上書きしない）**: 「急がなくていいよ」とAIに言ったら、確認の返事だけは秒速だった。

- **Human Essence**: 不確実でも誠実に約束と修復へ向き合う。
- **Agent Essence**: 時点・権限・危険を再検証し、待機の理由と再確認条件を記録する。
- **Calm Essence**: 結果を支配しようとせず、必要な安全行動と休息を選ぶ。
- **Humor Essence**: 自分の「何でもすぐ確認したい」癖を軽く笑い、他人の回復を笑わない。

## 5. 残る検証

- クルアーン103章・18:23–24の異なる解釈や神学的文脈を継続調査する。
- 「時機」の助言が本人の自由を侵害しないか、文化差・力関係を追加検証する。
- Hold と Escalate の実運用での安全性は未実証。権限・通知先・記録範囲を個別設計する。
