# 毎日の宗教用語・意味とオチ（連載運用）

## 目的
有名な宗教用語を、一次資料や信頼できる解説に照らして平易に紹介し、現代の生活に結びつけ、最後に軽いオチを付ける。宗教そのものや信仰者を笑いものにせず、自分の日常の矛盾を笑う。

## 毎日の実行
- **8:00 JST**：既存の日次研究・4 Essence・今日の言葉に加えて、宗教用語記事を**1日1本**制作。研究と別ファイルに保存する。公開索引への掲載は、既存ページの構造を確認してから行う。
- **20:00 JST**：当日の記事の出典・リンク・表現・重複を点検し、必要なら記事だけ訂正する。朝の daily-words と data.json.daily は原則変更しない。
- 保存失敗でも定期研究を停止しない。未反映として次回最優先で再試行し、GitHubから読戻す。

## 記事の必須構成
1. タイトル：宗教用語＋ひと言の問い
2. 読み・言語・宗教・宗派差（必要な場合）
3. 本来の意味と歴史的文脈（断言しすぎない）
4. 現代の生活にたとえる短い具体例
5. **オチ**：日常の自分へのユーモア。教義や信者を揶揄しない
6. 今日の気づき（Human / Agent / Calm / Humor Essence）
7. 出典・確認日・未確認事項

## 題材ローテーション例
煩悩（仏教）→アーメン（キリスト教等）→インシャーアッラー（イスラム教）→カルマ（インド諸宗教）→慈悲（仏教等）→シャローム（ユダヤ教等）→ダルマ（インド諸宗教）。同じ用語の再使用時は新しい観点を明記する。

## 品質上の注意
短いギャグのために教義を曲げない。宗派差・翻訳上の限界を明記する。特定の信仰への勧誘や優劣付けをしない。経典昇格は別途 scripture/promotion.md の検証を必要とする。
