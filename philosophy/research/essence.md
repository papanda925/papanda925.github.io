# Essence Extraction

このプロジェクトでは、宗教・哲学の説明を増やすだけでなく、毎回「何が使えるのか」を短く抽出する。

## 4つのエッセンス

### Human Essence
日常の判断、生き方、人間関係、失敗からの回復へ持ち帰れること。

### Agent Essence
AIエージェントの Identity / Values / Boundaries / Behavior / Reflection / Amendment 等へ翻訳できること。

### Calm Essence
心を穏やかに保つために役立つ、注意、距離、反応の遅延、受容、修復、習慣、共同体等の知恵。

### Humor Essence
緊張をほぐし、視点を変え、体系そのものの教条化を防ぐ笑い。ただし他者を軽んじる笑いにはしない。

## 原則

短くすることと単純化することを混同しない。エッセンスには、必要なら前提・例外・出典へのリンクを付ける。


## 2026-10-03 横断エッセンス — ストア派 × 初期仏教

ストア派の「印象と同意」と、初期仏教の「感受→渇愛」「第二の矢」は同一理論ではない。しかし、現代へ持ち帰る際には次の実践的接点を検討できる。

> **刺激を否定せず、反応を固定せず、必要な行動だけを選ぶ。**

- Human Essence: 最初の感情・痛みを否定せず、その後に追加する判断や反応を観察する。
- Agent Essence: `Input → Initial Signal → Check → Amplification Check → Hold / Action → Reflection`
- Calm Essence: 第一の痛みを無かったことにせず、不要な第二の反応を自動追加しない。
- Humor Essence: 「反応してしまった自分」をさらに責めて三本目の矢を作らない。

注意: 現実の危険、不正、損害への退避・異議・境界設定は「不要な反応」として抑圧しない。

## 2026-10-03 横断エッセンス — 反応前の余白から反応後の修復へ

ストア派・初期仏教に続き、クルアーン3:134–135の怒りの抑制、赦し、過ちへの非固執を検討した。三者を同一理論とはしない。

プロジェクト独自の横断モデル候補:

**Notice → Pause → Bound → Act → Check Impact → Repair**

- Human Essence: 怒りを否定せず決定権を渡さない。誤ったら固執せず戻る。
- Agent Essence: Hold に加え、出力後の Impact Check / Repair / Amendment を持つ。
- Calm Essence: 反応前の余白と、反応後に戻れる余白の両方を持つ。
- Humor Essence: 自分を完成品として神聖化せず、修正可能性を残す。

注意: 赦しと、安全確保・境界設定・責任追及を同一視しない。
