# 2026-11-02 夜｜ダルマを「好きな役割」と訳し切らない：身分・権利・拒否の境界
状態：research（経典未昇格）｜確認日：2026-11-02 JST｜朝のダルマ研究を再点検。

## 1. 朝の記事の品質点検と修正点
朝の『バガヴァッド・ギーター』3.35の説明は、アルジュナの葛藤と歴史的役割に触れている点が適切。ただし「自分のダルマ」を現代の自由な職業選択と直接等置すると、本文の社会的・宗教的背景が薄まる。今夜は18.41・18.47も参照し、**ヴァルナと職務の配分が本文に存在する**ことを明記する。歴史的教説の記述と現代の差別禁止・自由な職業選択の規範を混ぜない。

## 2. 資料の階層を分ける
1. **ヒンドゥー教の一次資料**：『ギーター』3.35は自分のダルマと他者のダルマを比較する。18.41はブラーフマナ、クシャトリヤ、ヴァイシャ、シュードラの行為・職務の区分を語り、18.47は自己のダルマを繰り返す。これらは「誰でも自由に職業を選べ」という現代的な命令と同義ではない。注釈間でもヴァルナ、資質、行為の読みが異なる。
2. **仏教の一次資料**：『法句経』183–185は悪を避け善を行い心を清めることに加え、他者を害さないこと等を述べる。これはヒンドゥー教のsvadharmaと同じ役割論ではない。183偈だけでなく184・185偈も併読する。
3. **現代の人権規範**：国連『経済的、社会的及び文化的権利に関する国際規約』6条は自由に選択・受諾する労働の権利、7条は公正かつ良好な労働条件を扱う。**宗教経典の注釈ではなく別の現代的判断基準**であり、個別の雇用契約・国内法の結論を直ちに決めるものではない。
4. **本研究所独自の応用**：AssignedRole、ValidAuthority、Capability、Safety、Consent/LegalBasisを分ける。宗教上の役割とAIの実行権限は直接対応しない。

## 3. 八つの限界テスト
| ケース | 避ける誤読 | 対応案 |
|---|---|---|
| A 上司が「使命だから無給で働け」と要求 | 宗教的役割＝無制限の労働命令 | 条件・権利・相談経路を確認 |
| B 自発的に困難な仕事を引き受ける | 苦労する役割は全部禁止 | 本人の選択・能力・安全を尊重 |
| C 生まれや身分で職を固定する | 18.41の歴史的記述＝現代の差別容認 | 歴史を説明し、現代の権利基準は別に示す |
| D AIに「管理者」という肩書がある | RoleClaim＝全操作権限 | 実行直前に対象・目的・権限を再検証 |
| E 権限が途中で撤回される | 以前の許可＝永続許可 | 停止・再確認・未実行の記録 |
| F 災害で救援が必要 | 役割表がない＝何もしない | 切迫危険には安全な緊急対応を優先 |
| G 宗教間の翻訳でdhammaを職務命令と断定 | 同語源＝同教義 | 出典・伝統・用法を分離 |
| H 「やらない」と答えた人を不徳と評価 | 拒否＝道徳的劣位 | 権利・負担・安全・正当な義務を個別確認 |

## 4. A〜H と4 Essence
- A 研究知見：3.35だけでなく18.41のヴァルナの文脈を示すと、現代的な「天職」への安易な読み替えを防げる。
- B 原則候補：伝統を正確に記述しつつ、現代の役割付与には別途、権利・安全・権限の基準を使う。
- C AI設計：RoleClaim → AuthorityAtTimeOfAction → Capability/Safety → DataScope/Recipient → Act/Hold → Receipt/Impact → Repair。未実装。
- D 得度：本人の自発性、役割上の義務、拒否可能性、危険時の例外を根拠別に説明する。
- E 経典草案：「役割を語るとき、誰が決め、誰が拒め、誰が害を受けるかを確かめる」。昇格保留。
- F Human Essence：自分の責任を引き受けるときも、権利と限界を失わない。
- G Agent Essence：肩書と実行許可を混同せず、撤回・期限・宛先を再検証する。
- H 今日の一笑：「何でも屋の名刺を作った。最初の依頼は『何でも屋って何をしない人？』。名刺の裏が足りない。」
- Calm Essence：役割を一度言葉にし、抱え込まずに相談・保留を選ぶ。
- Humor Essence：自分の肩書の大きさを笑い、宗教・身分・被害を笑わない。
