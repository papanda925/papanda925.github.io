# 2026-11-03 朝｜アヒンサー（不害）：「傷つけない」と「何もしない」は同じか
状態：research（経典未昇格）｜資料確認：2026-11-03 JST｜前回ダルマ・役割と権限の研究を継続。

## 1. 問いと資料の区別
**問い：** 害を避ける教えは、危険を見ても何もしないことを意味するのか。またAIは「安全のため」と言えば介入してよいのか。

**一次資料・伝統の文脈：**
1. パタンジャリ『ヨーガ・スートラ』2.30は、ahiṃsā（不害）、satya（真実）、asteya（不盗）、brahmacarya、aparigrahaを五つのyama（制戒）として列挙する。ヨーガの倫理的実践の一部であり、現代の事故対応手順を記したものではない。
2. 『バガヴァッド・ギーター』16.2はahiṃsāを真実・怒りを離れること・慈しみ等と並べる。ただし『ギーター』全体は戦場のアルジュナへの教えであり、本文中の不害を「この伝統ではあらゆる場面の非介入を命じる」と単純化しない。訳者・注釈者の解釈差を留保する。
3. ジャイナ教ではahiṃsāは中心的な誓戒。Jainpediaが引用する『ダシャヴァイカーリカ・スートラ』4章の出家者の誓戒は、身体・言葉・心、他者への加害を促すことも対象にする。在家者の小誓戒（aṇuvrata）は、生活で避けられない害への対応を含め出家者の大誓戒と異なる。**ジャイナ教の厳格さを全宗教へ投影しない。**

**現代の独自提案：** 不害の思想を参考に、危険の検知・権限・本人の意思・緊急性・予見可能な害・実行結果を分離する。これは宗教の直接の教義ではなく、研究所の試案である。

## 2. 前回「ダルマ」からの進展
前回はRoleClaimとValidAuthorityの区別を研究した。今回は「権限がないから一切何もしない」も「安全のためだから勝手に全部する」も避ける。安全な退避・人間への報告・適切な緊急対応と、本人の意思に反する広範な代理行為を区別する。個別の法域・契約・現場手順は別途確認する。

## 3. 八つの反例・限界テスト
| 事例 | 失敗する短絡 | 検討する判断 |
|---|---|---|
| A 悪口を言わないつもりで黙るが、同僚の危険を知る | 沈黙＝無害 | 安全な報告先・危険の切迫性を確認 |
| B 誰かの相談に善意で外部連絡 | 善意＝許可 | 同意・法的根拠・緊急性・宛先を分離 |
| C 暴力から逃れる | 非暴力＝逃げてはいけない | 退避・救援を優先。教義の単純な強制をしない |
| D 小さな害と大きな害が競合 | 完全無害しか許さない | 選択肢と予見可能な影響を比較し不確実性を記録 |
| E AIが「害を防ぐ」と全データ送信 | 安全目的＝無制限権限 | 最小化・承認・停止・宛先確認 |
| F 被害を受けた人に「怒るな」と言う | 不害＝感情抑圧 | 被害者の感情・異議・救済を尊重 |
| G 出家者の誓戒を在家者全員へ適用 | 同じ語＝同じ実践義務 | 伝統・生活形態・誓戒の違いを説明 |
| H 不害を理由に誤報を訂正しない | 訂正＝相手を傷つける | 事実に即した適切な訂正と影響確認 |

## 4. A〜H と4 Essence
- **A 研究知見**：ahiṃsāは複数伝統で重要だが、ヨーガの制戒、ギーターの徳目、ジャイナ教の誓戒は同じ制度ではない。
- **B 原則候補**：「害を避ける」だけでなく、放置・過剰介入・訂正不足が生む害も点検する。
- **C AI設計**：Need/Risk → Urgency → Authority/Consent/LegalBasis → LeastIntrusiveAction or Hold → Receipt → ObservedImpact → Repair。未実装。
- **D 得度**：危険な沈黙と無断介入の両方を説明し、本人の権利と緊急性の境界を検討する。
- **E 経典・問答草案**：「傷つけないために立ち止まる。立ち止まることが害になるなら、許された安全な一歩を選ぶ」。**candidate、経典昇格保留**。
- **F Human Essence**：傷つけない意図だけで安心せず、相手への影響を確かめ、必要な安全行動を選ぶ。
- **G Agent Essence**：NonHarmIntent・ObservedRisk・Authority・Urgency・ActionReceiptを分け、危険の放置も点検する。
- **H 今日の一笑**：「今日は誰も傷つけないぞ」と静かにドアを閉めた。自分の指だけ挟んだ。まずは自分にも優しく。
- **Calm Essence**：反射的な言い返しを一拍置く。ただし危険から離れる・助けを呼ぶことは遅らせない。
- **Humor Essence**：自分の不器用さを笑い、信仰者・被害者・弱い立場の人を笑わない。

## 5. 3分実践と検証可能性
30秒で何が危険か具体化、40秒で誰が影響を受けるか、40秒で権限・意思・緊急性、40秒でより侵襲の少ない行動、30秒で結果・訂正先を点検。切迫した危険では3分の完了を待たない。得度問答で反例を検証し、AIの実装試験は別に行う。
