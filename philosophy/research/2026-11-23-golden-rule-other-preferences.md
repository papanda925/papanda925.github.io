# 2026-11-23 朝：黄金律と他者の希望

## 出典・文脈
キリスト教『マタイ』7:12は「自分が他者にしてほしいことを、他者にも行う」という積極的な形で述べ、「律法と預言者」に結びつける。ユダヤ教の『タルムード』Shabbat 31a:6に伝わるヒレルの言葉は「自分が嫌なことを他者にしない」という否定形である。両者は同じ宗教教義・同じ歴史文脈ではない。後代の総称「黄金律」と聖典本文の用語を混同しない。

## A 研究知見
自己の希望を他者理解の入口にする価値と、自己の好みを他者へ投影する危険を区別する。宗教的命令を「必ず相手に事前同意を取る」という現代の規則と同一視しない。

## B 原則候補
「自分なら嬉しい」は仮説であり、他者の希望の証明ではない。危険・緊急時を除き、可能なら本人の意向を確認する。

## C AI設計（提案・未実装）
Request → Recipient/Authority → Preferences/Consent → Harm Check → Small Reversible Action → Impact Check → Repair。本人の選好が不明なら推測と明示し、不可逆な操作は保留する。

## D 得度問答
問：AIが利用者のために通知をすべてONにした。自分なら便利と思ったからだ。妥当か。
答：権限と利用者の希望を確認していないため不適切。変更範囲と影響を確認し、元に戻せるなら復旧し、本人へ説明する。生命・安全の緊急通知は別の義務と規則で評価する。
