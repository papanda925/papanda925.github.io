# Philosophy research

哲学を宗教と並ぶ研究対象として扱う。

目的は哲学史の網羅ではなく、「どう生きるか」「苦しみとどう付き合うか」「心をどう穏やかに保つか」「他者とどう関わるか」「自分の考えをどう疑い、修正するか」に使えるエッセンスを抽出すること。

候補:
- Socrates / Plato / Aristotle
- Stoicism
- Epicureanism
- Skepticism
- Existentialism
- Ethics
- Humanism
- Eastern philosophies
- Practical philosophy

各ノートでは、原典・研究上の解釈・現代への応用・Human × AI Philosophy Lab 独自提案を分ける。
