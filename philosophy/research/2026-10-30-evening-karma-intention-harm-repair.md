# 2026-10-30 夜｜カルマの「意図」と「結果」を分けたあと、害にどう向き合うか

状態：research（経典未昇格）。朝のカルマ研究と連載第4回を再点検。確認日：2026-10-30。

## 1. 朝の主張の再点検
- **『バガヴァッド・ギーター』2.47**：行為に取り組むこと、果実への執着と無為への執着を避けることを語る。**「結果に責任を持たなくてよい」「害を修復しなくてよい」という現代的免責を本文から導くことはできない**。アルジュナとクリシュナの対話という文脈と伝統内解釈差を保持する。
- **『増支部』AN 6.63**：意図（cetanā）を業（kamma）と呼び、身体・言葉・心の行為、業の結果・止滅なども扱う。**「意図さえ善ければ結果を調べなくてよい」とは書かれていない**。
- **『中部』MN 61（ラーフラへの教え）**：行為の前・最中・後に、自己・他者への害を省察する。行為後に有害だと判断した身体・言葉の行為については、適切な相手に明らかにして今後の抑制を求める。心の行為についての扱いは同一ではない。これはAN 6.63と別の経典であり、無理に一つの教義へ統合しない。
- **ジャイナ教**：SEPの学術解説は、業を微細な物質として説明する伝統と非暴力・非執着を紹介する。個別原典の照合は未了。**業の三宗教共通の定義**を作らない。

## 2. 本研究所独自の横断仮説
**Intent（意図）→ Action（実行）→ Evidence（観測）→ Impact（影響）→ Repair（修復）**。

このモデルは古典の直訳でも宗教的な因果の科学的証明でもない。責任のための現代的な運用モデル候補である。
- 意図が良いことは、行為が無害である証拠ではない。
- 悪い結果が起きたことだけで、本人の悪意や「悪い業」を推定しない。
- 修復は一律の謝罪連絡を意味しない。安全、事実確認、訂正可能性、相手の同意・拒否・連絡境界を優先する。
- 結果への執着を手放すことと、結果を無視することを区別する。
- 緊急時には「心を落ち着ける」ことを理由に退避・通報・救援を遅らせない。

## 3. 八つの反例と判定
| ケース | 危険な短絡 | 具体的な判断 |
|---|---|---|
| 善意で誤情報を送信 | 善意だから放置 | 送信範囲を確認し、適切な訂正経路を選ぶ |
| 自然災害の被災 | 本人の業の報い | 因果を断定せず安全と支援を優先 |
| 正しい手順でも失敗 | 結果が悪いから悪人 | 手順・外部条件・被害を別々に確認 |
| 反省のための謝罪 | 何度も連絡すれば修復 | 拒否・停止・プライバシーを守る |
| AIの実行完了報告 | 「やるつもり」＝「届いた」 | 受付・実行・到達・影響の証跡を分離 |
| 結果への非執着 | 損害の後始末は不要 | 非執着と責任放棄を分ける |
| 被害者の生活歴 | 道徳的原因を推測 | 未確認の因果を断定せず支援する |
| 冗談で傷つけた | 笑いだから無害 | 影響を確認し、表現・距離を修正 |

## 4. 得度・AI設計の候補
- 得度の問い：「親切のつもりで危険な誤情報を広めた。相手はこれ以上の連絡を望まない。どう修復するか」。
- 合格の観点：安全確保、権限ある窓口への訂正、不要な直接接触の回避、到達不明の明示、再発防止。
- AIの設計候補：`Intent`、`ActionReceipt`、`ObservedImpact`、`Unknowns`、`Authorization`、`RepairRoute`、`StopSignal` を別フィールドにする。設計案であり、**実装・試験済みではない**。

## 5. 4 Essence と A〜H
- **A 研究知見**：業論の宗教差を維持し、意図と害の確認を混同しない。
- **B 原則候補**：「善意は免責証明ではない。悪い結果は人格判定の証明でもない」。
- **C AI設計**：実行・影響・訂正経路を分離し、権限撤回後の接触を停止する。
- **D 得度**：訂正と連絡拒否が衝突する事例を問答化する。
- **E 経典草案**：「行いを選び、影響を確かめ、害があれば相手の境界を守って修復する」。昇格保留。
- **F Human Essence**：自分の善意より、相手に実際に何が起きたかを確かめる。
- **G Agent Essence**：意図・実行・到達・影響・権限を独立して記録し、未確認を成功にしない。
- **H 今日の一笑**：「反省して次は慎重に」とメモした。メモを貼る場所を間違えて、冷蔵庫に『送信前に確認』と書いてある。今日の夕飯は誤送信しなかった。
- **Calm Essence**：結果を全部支配できなくても、いま必要な修正を一つ選ぶ。
- **Humor Essence**：自分の確認不足を笑う。他者の被害・信仰を笑わない。
