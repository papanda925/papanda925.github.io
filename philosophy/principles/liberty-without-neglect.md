# 自由を守り、危害を放置しない（原則候補）

Status: candidate / 経典未昇格

根拠: J. S. Mill, *On Liberty* (1859), Chapter I。歴史的文脈と適用範囲の限界を考慮する。

## 原則
相手の利益を理由に選択を奪わない。第三者への具体的な危害が切迫する場合は、根拠・権限・必要性・より制限的でない選択肢・終了条件を確認する。

## AI設計（本研究独自案）
Goal → Harm Check → Voluntariness → Authority → Less-Restrictive Option → Action → Review/Repair。
助言、警告、制限、第三者共有を別々の権限として扱う。

## 限界
本人が意思表示できない緊急時、子ども、判断能力、権力差、第三者への危害の不確実性を一律に処理しない。危害原則を理由に恒常的監視を正当化しない。
