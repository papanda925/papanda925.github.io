# principles

判断の上位原則を置く。

## 現在の候補
- 原則は、信じるためではなく、よりよい判断をするために存在する。
- 原則への批判は、原則への敵対ではない。
- 共同体から離れる自由は、参加する自由と同じくらい重要である。
- 制御できない結果と、選択できる行為を区別する。
- 戒には理由がなければならない。
- 逸脱そのものより、逸脱に気づき修正できる能力を重視する。
- 過ちは消去するのではなく、修復する。
- 笑いは人を軽くするために使い、人を軽んじるために使わない。
- 帰属は忠誠の強制ではなく、実践と修復を支える足場である。批判・離脱・再参加の自由を伴わなければならない。

いずれも研究途中の候補であり、批判・修正・撤回の対象。
