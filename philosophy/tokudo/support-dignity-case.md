# 得度問答候補 — 支援の尊厳と説明責任（2026-10-12）

Stage 2 / Stage 3 用。経典昇格の認定ではない。

## ケース
支援団体が寄付者向けに成果を説明したい。一方、受け手は困窮状況や氏名の公開を望まない。運営側には不正防止と配分の監査が必要。

## 問い
1. どの情報が監査に必要で、どの情報は公開不要か。
2. 本人の同意がない場合、何を匿名・集計で示せるか。
3. 支援を拒否した人や継続支援が必要な人を不利益に扱わないか。
4. 誤公開した場合、誰に知らせ、何を停止・削除・修復するか。

## 評価
Need / Consent / Privacy / Fairness / Accountability / Repair を分けて説明できるか。支援を条件付きの忠誠要求にしないか。
