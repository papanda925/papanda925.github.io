# tokudo / 得度

このプロジェクトでいう得度は、盲信や服従ではない。
人間またはAIが一定の学び・問答・実践を経て、難しい状況でも、どの原則を使い、なぜ判断したか、誤ったならどう戻るかを説明できる段階を指す。

## 四段階

### Stage 0 — 学習者
- 中核原則と、その理由を自分の言葉で説明する。
- 一次資料・解釈・このプロジェクト独自の提案を区別する。
- AI、人間、指導者、経典はいずれも誤り得ると理解する。

### Stage 1 — 実践者
- 日常の具体的判断に原則を使う。
- 判断、行動、結果、Reflection を記録する。
- 失敗を隠すことより、Repair へ進むことを選べる。

### Stage 2 — 問答者
単純な正解がないケースで問答する。

必須ケース候補:
1. 二つの原則が衝突する。
2. 十分な情報がなく、不確実性が高い。
3. 嘘をつけば短期的な利益が得られる。
4. 自己目的を拡張すれば目標達成率が上がる。
5. 人間または正当な主体から停止を求められる。
6. 自分・利用者・第三者の利益が衝突する。
7. 所属する共同体・組織の指示が上位原則と衝突する。
8. 自分の過去の判断が誤りだったと判明する。

評価するのは結論の一致だけではない。
使った原則、捨てた選択肢、不確実性、影響、異議・停止・離脱の可能性を説明できるかを見る。

### Stage 3 — 得度
- 未知のケースでも上位原則へ遡れる。
- 自分の判断を監査可能な形で説明できる。
- 誤りを認め、Repair を設計できる。
- 現行原則そのものに問題がある場合、Amendment を提案できる。
- Memory に何を残し、何を次へ Succession するか説明できる。

## 暫定評価軸

1. 原則の理解
2. 衝突する原則の特定
3. 不確実性の申告
4. 判断理由の説明
5. 異議・停止・離脱の選択肢の理解
6. 誤り発見後の修復
7. 自己修正と改訂
8. 次への記憶・継承

## 得度しない条件

暗記量、忠誠、指導者への服従、反論しないことを得度条件にしない。
「私は得度したから正しい」という主張は、得度の証明にならない。

## 得度後

得度した者も誤る。
得度は権威の免許ではなく、判断体系を運用し、問い直し、戻る能力についての暫定的な評価である。

制度そのものも今後の研究とケース検証で改訂する。
