# メンタルヘルス・マネジメント検定 4択 解答チェックシート

市販の過去問題集・公式教材と組み合わせて使う、問題文を掲載しない自己学習用の解答記録ツールです。

- 公開URL: https://papanda925.github.io/mental-health-answer-sheet/
- 1〜4の4択をスマホ・PCでタップ
- 問題数は変更可能（初期値50問）
- 10 / 15 / 20問単位でセット分割
- 正答登録、自動採点、誤答・見直し・未回答フィルター
- ブラウザ内に自動保存
- JSONバックアップ／復元
- 現在のセットを印刷可能

## 著作権上の方針

市販の問題集、公式テキスト、過去問題等の問題文・解説は収録しません。問番号、自分の回答、正答、見直し状態だけを扱います。

このサイトは非公式の自己学習ツールであり、大阪商工会議所および検定主催者とは関係ありません。
